# portfolio_form_design

Redesign proposal for the model portfolio **Preferences → Exclusions** form.

Live page: https://serhiihaniuk.github.io/portfolio_form_design/

A single standalone HTML file (`index.html`) with no build step and no dependencies apart from a web font. All interactions work:

- Search a category and tick items, or press Enter to add the top match
- Grey **+** chips are suggestions; click to exclude
- Pink chips are exclusions; × removes them
- Credit rating and ESG use a cut-off scale (click a grade to move the red line)
- Excluded instruments: search by ISIN or name
